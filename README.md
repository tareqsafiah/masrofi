# مصروفي 💸

تطبيق شخصي لتتبع المصاريف الشهرية، اكتشاف الإنفاق غير الضروري، ومحفظة ادخار بالدولار مع اقتراحات ذكية.

## التثبيت على الآيفون (بدون Apple ID)
1. افتح من **Safari**: https://tareqsafiah.github.io/masrofi/
2. اضغط زر **المشاركة** ثم **إضافة إلى الشاشة الرئيسية**.

كل رفع إلى `main` يبني نسخة جديدة وينشرها تلقائياً (GitHub Actions → Deploy Web App).

## قاعدة البيانات
- البيانات تُحفظ على الهاتف، وتُنسخ تلقائياً إلى ملف **مشفّر (AES-256-GCM)** في فرع `data` من هذا المستودع (`masrofi.enc.json`).
- التشفير يتم على الهاتف بكلمة سر تختارها، ولا يمكن قراءة الملف بدونها.
- يلزم رمز وصول GitHub (Fine-grained token) بصلاحية **Contents: Read and write** على هذا المستودع فقط.
- عند حذف بيانات المتصفح: افتح التطبيق ← "استعادة من قاعدة البيانات" ← أدخل الرمز وكلمة السر.

## نسخة iOS أصلية (اختياري)
ملف `build-ios.yml` يبني ملف IPA عند تشغيله يدوياً من تبويب Actions.
