# مصروفي 💸

تطبيق شخصي (Flutter / iOS) لتتبع المصاريف الشهرية، اكتشاف الإنفاق غير الضروري، ومحفظة ادخار بالدولار مع اقتراحات ذكية.

## بناء ملف IPA
كل رفع إلى main يشغّل GitHub Actions على جهاز Mac سحابي ويُنتج ملف masrofi.ipa (من تبويب Actions ← آخر بناء ← Artifacts).

## التثبيت على الآيفون من ويندوز
1. ثبّت iTunes (من موقع آبل) و Sideloadly من sideloadly.io.
2. صِل الآيفون بالكابل واضغط ثق.
3. اسحب masrofi.ipa إلى Sideloadly، أدخل Apple ID واضغط Start.
4. على الآيفون: الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق.
5. iOS 16+: الإعدادات ← الخصوصية والأمان ← وضع المطوّر ← تفعيل.

مع Apple ID مجاني تنتهي صلاحية التوقيع كل 7 أيام؛ أعد التثبيت بنفس الملف وبياناتك تبقى محفوظة.
